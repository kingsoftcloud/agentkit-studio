## 产品能力

<Cards>
  <Card title="Agent 创作">分步表单、修订版本、冻结运行时，改配置不影响已经在跑的会话。</Card>
  <Card title="三运行时">DSH Native、Star Harness、Codex 三条执行路径，能力矩阵一目了然。</Card>
  <Card title="资源绑定">MCP Server、Skill、知识库、Memory 挂到某个修订版本上，凭证只留在 Host。</Card>
  <Card title="部署上云">托管运行时 7×24 常驻，19 个部署状态可观测、可回滚。</Card>
  <Card title="专家与团队">专家模板、专家团、本地团队会话，复用同一套编辑与冻结语义。</Card>
  <Card title="插件生态">DSH 插件市场、Codex 插件、远程索引与就绪校验。</Card>
</Cards>
