## v0.0.24

### 你会注意到

- **总览可以直接继续工作。** 已有 Agent 时展示最近 Agent、24 小时运行、待执行自动化和工作区状态，并能一键进入对应对话；零 Agent 时显示创建方式和三步引导，不再看到空统计。
- **第一次配置模型更清楚。** 缺少凭证或没有可用模型时会明确引导；模型目录补充上下文窗口、视觉能力、推理档位和提供商名称，保存预算与目录探测也更稳定。
- **选模信息更丰富。** 启用 RouteMind 后可查看模型评分、雷达图和相对价格；Star Harness 插件详情保留签名版本、升级与回退能力。
- **中断任务可以接着跑。** 明确的续跑指令会恢复原 Star Harness Run 和事件游标，不会重复执行已经完成的工具调用；TokenUsage 在原生自动化与 Runtime Responses 中继续保留。
- **KSXC 不可达时不再误导。** 内部运行时入口会暂时隐藏，网络恢复后自动还原；既有 KSXC Agent 仍可编辑并保留模型绑定。
- **云端实例不再因 YAML 格式差异卡住。** ManagedRuntime 比较解析后的声明，真正发生漂移时进入 `ACTION_REQUIRED`，可在部署面板修复，而不是一直显示「准备实例」。

### 升级说明

无破坏性变更，直接升级即可。本版同时更新总览、DSH Native、配置参考和发布文档。

## v0.0.16

### 你会注意到

- **图片不再丢。** 已发送的图片在缩略图、放大视图和历史刷新后都还在；纯图片消息也能正常显示。
- **每轮耗时更准。** 纯回答的轮次改用已提交的起止时间，不再被网络抖动拉长。
- **工作区各连各的 Harness。** 在 Alpha / Beta 工作区之间切换，模型、工作目录和历史各自跟随，不再串。
- **入口文案变了。** 「手动配置」现在在 **更多创建方式** 菜单里；运行时选择从下拉框变成单选组。
- **过程默认折叠。** 失败轮次用中性色摘要展示，展开才看完整原因；用量固定在输入框底部。

### 破坏性变更

| 变更 | 影响 | 你要做什么 |
| --- | --- | --- |
| 移除生产进程内 Harness | 依赖进程内执行的自定义部署会失败 | 改成独立 Harness 服务或显式外部命令 |
| 删除旧 `sessions/native-*` 控制入口 | 调用这些 operation 的集成会拿到 `STUDIO_LEGACY_HARNESS_RETIRED` | 迁移到新入口 |
| 移除三个 `bundledDependencies` | npm 包不再内联 Harness Core/Node/UI | 显式声明依赖 |
| 移除 `publishConfig.executableFiles` | 本地进程 launcher 不再随包发布 | 不要依赖包内 launcher |
| 未绑定目录明确拒绝 | 不再回落到其他项目 | 补齐工作区绑定 |

详细步骤见[升级到 v0.0.16](./upgrade-to-0.0.16.mdx)。

## v0.0.15

| 你会注意到 | 说明 |
| --- | --- |
| 任务能投递到独立服务 | 原生会话、Team 角色、绑定的 A2A 任务都走独立 Harness 服务；桌面端能重连回原始 Run |
| 界面统一 | Agent 表单合并为三步；资源库、交付、运行中心统一 DSH 设计 token |
| 新建 Agent 默认 DSH Native | 创建流程中暂时隐藏 Star Harness（编辑既有 Star Harness Agent 不受影响） |
| MCP 资源页更紧凑 | 「认证 Header / 环境变量凭证」收进可折叠进阶区块，识别到自定义 Header 时自动展开 |
| 浅色主题按钮可读了 | 主按钮 hover 不再把白色标签变成浅色底 |
| 部署详情显示镜像 tag | 更新检查拆成当前镜像与目标镜像（tag + digest） |

内部变化（不影响你的操作）：托管 Codex 的超时环境变量进白名单、Hosted UI 会话注册表改 Agent 作用域、
冻结 host 的 MCP 轮次预算改为 15 分钟（`AGENTKIT_RUNTIME_TIMEOUT_MS` 可调）、浏览器 bundle 尺寸成为门禁。

## v0.0.14

| 你会注意到 | 说明 |
| --- | --- |
| 插件市场能发现了 | 聚合 npm `keywords:dsh-plugin` 与 GitHub `topic:dsh-plugin`，带分类筛选、下载/星标排序、详情卡与一键安装 |
| 更新不再逐版前进 | 每次发布自动把同一份 feed 镜像到兼容车道，历史安装能一步跳到最新 |
| 长会话不容易被压缩 | 模型上下文窗口改从模型网关 `/v1/models` 的 `context_length` 读取，不再固定 128000 |
| 插件不兼容时报因清楚 | 云端镜像目录出现新能力声明时，只停用该镜像版本并回退，不会让整个环境不能部署 |
| 云端 Codex 默认全权限 | 容器已是隔离边界，Codex 自带沙箱在只读 rootfs 里起不来；可用 `AGENTKIT_CODEX_SANDBOX` 收窄 |
| 资源部分不可用也能聊 | 默认降级运行；`AGENTKIT_STRICT_RESOURCES=1` 恢复 fail-closed |

## 怎么判断要不要升

| 你的情况 | 建议 |
| --- | --- |
| 用了自定义进程内 Harness | 升级前先读[升级到 v0.0.16](./upgrade-to-0.0.16.mdx) |
| 只做本地 Agent 创作 | 直接升，无破坏性影响 |
| 依赖插件市场 | 升到 0.0.14 或更高才有发现能力 |
| 需要多工作区隔离 | 必须 0.0.16 |
