AgentKit Studio 有两种用法，先确认你要哪一种：

<Tabs items={['桌面端（推荐）', '作为 DSH 插件', '从源码开发']}>
  <Tab value="桌面端（推荐）">
    从[下载页](https://kingsoftcloud.github.io/agentkit-studio/)获取最新的签名安装包（exe / dmg），
    双击即可使用。适合绝大多数用户，不需要 Node.js、pnpm 或任何构建工具。
  </Tab>
  <Tab value="作为 DSH 插件">
    在已有的 DeepSeek Harness 环境里安装 `@kingsoftcloud/agentkit-studio`，
    把 Studio 的能力挂到你自己的 Host 上。适合已经有 DSH 工作流的团队。
  </Tab>
  <Tab value="从源码开发">
    参与开发、调试补丁或验证真实 Host 行为时使用。需要 Node.js 24 与 pnpm 10。
    见[贡献指南](../contributing/index.mdx)。
  </Tab>
</Tabs>

## 开始之前

| 你需要 | 说明 |
| --- | --- |
| macOS 13+（Apple Silicon）或 Windows 11（x64） | macOS 为签名并公证的 DMG；Windows 为 NSIS 安装器 |
| 一个模型供应商的 API Key | 支持任意 OpenAI 兼容端点，或使用组织内配置的模型网关 |
| 可选：云端凭证 | 只有「把 Agent 部署到云端」时才需要 |

<Callout type="warn" title="云端能力需要控制面">
  部署、托管运行时、知识库、记忆库依赖 AgentEngine 控制面与凭证。本地能跑通不代表云端资源可用——
  详见[产品与云端的关系](../concepts/managed-runtime.mdx)。
</Callout>
