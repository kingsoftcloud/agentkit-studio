Studio 的界面只有两层：**左侧面板**和**面板内的二级标签**。没有第三层导航，也没有需要学习的路由。

<Callout type="info" title="先记住一件事">
Studio 是 DSH 宿主里的一个产品插件，界面状态全部在内存里。**不存在 `/agents/123` 这样的 URL**——刷新浏览器会回到默认面板。
详见[为什么没有 URL](#为什么没有-url)。
</Callout>

## 全局骨架

每个面板的顶部都有同一套 chrome（`src/client/components/shell.mjs:46-49`）：

| 元素 | 位置 | 说明 |
| --- | --- | --- |
| 面板标题 | 左上 | 当前面板名，取自 `PANELS` 的 `label` |
| Host 状态胶囊 | 右上 | 三态：**Host 已连接** / **读取 Host** / **Host 待接入** |
| 页面动作 | 右上 | 面板自己的主操作按钮 |

Host 状态胶囊会先请求 `health()`，失败时再退到 `bootstrap()`；只有 `health` 通过且 `workspaceReady !== false` 才显示「已连接」（`shell.mjs:11-29`）。

## 四个面板

面板定义在 `src/client/theme.mjs:19-24`，顺序即左侧导航顺序：

| 面板 | 内部 id | 一句话 | 图标 |
| --- | --- | --- | --- |
| **总览** | `overview` | 工作区状态 | ⌂ |
| **智能体** | `agents` | 我的智能体与模板广场 | ✦ |
| **资源库** | `resource-hub` | 模型、工具与运行资源 | ◈ |
| **运行中心** | `operations` | 构建、部署与观测 | ↗ |

### 总览

打开就能看到「现在能不能开始干活」：

| 区块 | 能做什么 | 依据 |
| --- | --- | --- |
| 凭证提醒条 | 未配置模型凭证时提示「先配置一个模型凭证，即可开始对话」，并跳转设置 | `src/client/pages/overview.mjs:44` |
| 创建 Agent | 三个入口：**对话创建**（和 AI 一起完善配置）、**手动配置**（选择运行时与能力）、**从模板开始**（复用专家模板） | `overview.mjs:45-49` |
| 工作区 | 四个统计卡：Agent、运行时、资源、交付；**Agent / 资源 / 交付**可点击跳转 | `overview.mjs:50-53` |
| 启动检查 | 折叠区，展开后跑三项检查并显示 `confirmed` / `missing` / `unknown` | `overview.mjs:54` |

「启动检查」的三项固定是 **Host 连接**、**模型凭证**、**运行目标目录**（`src/client/state/start-checks.mjs:22-26`）。三项都有 8 秒超时，超时记为 `unknown` 而不是失败。

<Callout type="warn" title="三种状态的含义">
**已确认** = 读到了真实配置；**缺少配置** = 明确没配；**未知** = 读不到（超时、连接失败、目录未提供）。
「已确认」**不代表**工具执行或模型调用已经验证通过——同一句话在检查区底部也写了一遍。
</Callout>

### 智能体

二级标签只有三个（`src/client/pages/agents.mjs:170`）：

| 标签 | 内容 |
| --- | --- |
| **本地** | 本机工作区里的 Agent 列表 |
| **云端** | 已部署到云端的 Agent |
| **运行目标** | 当前 Host 可用的执行目标目录 |

「运行目标」读的是 `runtimeCatalog`，整页有三个状态：正在读取 / 目录已读取 / 运行目标不可用（`src/client/pages/runtime-catalog.mjs`）。每一行另有自己的可用性：「未启用」意味着 Host 没注册对应 capability，需要去插件中心安装并启用官方插件。

### 资源库

一级标签是**六类资源**（`src/client/pages/resources.mjs:45-48`）：

| 资源类型 | 二级标签 | 说明 |
| --- | --- | --- |
| 模型 | — | 模型配置与凭证引用 |
| MCP | 资源广场 / 已安装·已连接 | 探测通过只代表连接和工具列表读取成功 |
| Skill | 资源广场 / 已安装·已连接 | 本地已导入 ≠ 云端可用 ≠ 依赖已验证 |
| 知识库 | — | 每类默认绑定一个 |
| 记忆库 | — | 每类默认绑定一个 |
| 运行资源 | — | 运行目标带出来的资源 |

<Callout type="info" title="资源库不管绑定">
资源库只负责资源目录生命周期：发现、导入、探测、查看、删除、状态刷新。
**新增或变更 Agent 绑定关系**要在 Agent 创建页或编辑页完成。
</Callout>

### 运行中心

五个二级标签（`src/client/pages/operations.mjs:23`）：

| 标签 | 看什么 | 二级视图 |
| --- | --- | --- |
| **构建与部署** | 构建产物、部署记录、环境、日志 | 筛选：当前 Agent / 全部 |
| **自动化** | 定时与触发任务 | 状态：待执行 / 执行中 / 需关注 / 已暂停；作用域：本地 / 云端部署 |
| **评测** | 评测任务与通过率 | 详情：用例 / 断言 |
| **观测** | Trace 列表与 Span 详情 | 详情：属性 / 事件 / 资源 / 轨迹 / 原始 OTLP |
| **Channels** | 远端渠道绑定与审批 | 审批：申请人 / 渠道 / 会话 / 状态 |

## 设置

Studio 往 DSH 的设置对话框里**注入了两节**，而不是自己造一个设置页（`src/client/dsh/mount.mjs:301-305`）：

| 设置节 | 顺序 | 里面有什么 |
| --- | --- | --- |
| **模型与凭证** | 190 | 模型列表、当前运行模型、默认模型、输入能力、思考等级、API Key、提供商 |
| **AgentKit Studio** | 200 | 本机运行（会话绑定策略、默认执行目标、Studio Host、下一句提示）+ 版本与更新（三个版本号、桌面更新） |

「模型与凭证」的编辑是**方案 C**：任何字段改动先写进内存草稿，只有「保存配置」才落到 Host 存储。所以切走会有「未保存」提示，刷新会丢草稿（`src/client/pages/model-settings.mjs` 的 `data-unsaved` 分支）。

## 插件页

**DSH 插件页**是产品内的插件市场（`src/client/pages/dsh-plugins.mjs`）：

- **15 个分类**：全部、视觉外观、界面增强、记忆与上下文、搜索与联网、图像与媒体、文档与办公、模型与路由、成本与用量、效率与通知、协作与工作流、输入与编辑、安全与质量、助理、其他。
- **4 种排序**：推荐、下载量、最近更新、名称。
- **插件状态**：已启用、可安装、已停用、部分加载、加载失败、已配置、未安装、验证通过、验证失败、待重启。
- 「已安装」在第二个标签里管理，与「发现」分开。

## 为什么没有 URL

`page` 是一个 React state，切换面板调的是 `onNavigate('studio-operations')` 这样的字符串（`src/client/pages/overview.mjs` 与 `src/client/operations-focus.mjs:14`），不是 `history.pushState`。

| 你想要 | 现实 |
| --- | --- |
| 收藏某个 Agent | ❌ 不支持，用会话历史找 |
| 分享一个部署详情链接 | ❌ 不支持，只能截图或导出 |
| 浏览器后退回到上一个面板 | ❌ 后退会离开 Studio |
| 刷新后回到原面板 | ❌ 回到默认面板 |

只有少数界面状态会持久化到 `localStorage`：

```text
agentkit-studio:agents-view          # 智能体面板上次的二级标签
agentkit-studio:resource-kind        # 资源库上次的资源类型
agentkit-studio:resource-library-view # 资源广场 / 已安装
agentkit-studio:resource-tab         # 资源详情上次的标签
agentkit-studio.prompt-prediction.enabled # 下一句提示开关
```

这些是**偏好**，不是导航状态——它们只影响下次打开时的默认选项。
