## 四个配置文件

Studio 的配置没有环境变量化的入口，全部落在这四个文件里；改配置等于改代码，走同一个 PR 评审。

| 文件 | 作用 | schema |
| --- | --- | --- |
| `src/product.json` | 产品身份、文案、桌面打包输入 | `1` |
| `studio.plugin.json` | 插件清单：版本、Host 要求、能力与贡献点 | — |
| `dsh-pin.json` | DSH 基座固定：版本、提交、补丁目录 | `1` |
| `cordis.patch.yml` | 在官方 DSH 基座之上启用/禁用/插入模块 | — |

## `src/product.json`

产品身份与打包输入。`copy` 是唯一的可选段，按 namespace 与 locale 贡献词条。

| 键 | 值 | 说明 |
| --- | --- | --- |
| `schemaVersion` | 1 | 产品配置 schema 版本 |
| `brand.name` | `AgentKit Studio` | 插件展示名与桌面标题 |
| `brand.shortName` | `AgentKit` | 窄空间简称 |
| `versionSources.plugin` | `package.json#version` | 插件版本唯一来源 |
| `versionSources.desktop` | `explicit-build-version-or-dsh-version` | 桌面版本解析规则 |
| `copy.<namespace>.<locale>.<key>` | object | 可选产品文案，支持 `{productName}` 模板 |
| `desktop.appId` | `com.kingsoftcloud.agentkit-studio` | 桌面 App ID |
| `desktop.pluginRoots` | `@kingsoftcloud/agentkit-studio, routemind-studio` | 插件根包 |
| `desktop.defaultBundles` | `@kingsoftcloud/agentkit-studio` | 新 Profile 默认启用 |
| `desktop.updates.environment` | `production` | 更新环境 |
| `desktop.updates.origin` | [release-origin] | 发行物 HTTPS 源（此处脱敏） |
| `desktop.updates.channel` | `nightly` | 更新通道 |
| `desktop.platforms.<platform>.icon` | path | 平台图标，相对 `src/` 解析 |
| `desktop.platforms.<platform>.trayIcon` | path | 托盘图标 |

## `dsh-pin.json`

DSH 基座固定。裸 commit SHA 与摘要值属于内部信息，本页统一替换为占位符，实际值以仓库文件为准。

| 键 | 值 | 说明 |
| --- | --- | --- |
| `schemaVersion` | `1` | pin 文件 schema |
| `repository` | `[dsh-repository]` | DSH 上游仓库（此处脱敏） |
| `version` | `0.2.2-rc.1` | 固定的 DSH 版本 |
| `ref` | `dsh-v0.2.2-rc.1` | 固定 tag |
| `commit` | `[commit-sha]` | 固定提交，本页不展示裸 SHA |
| `baseCommit` | `[commit-sha]` | 基线提交 |
| `patchedTree` | `[commit-sha]` | 打补丁后的树对象 |
| `hostContract` | `1` | Host 契约号 |
| `nodeRange` | `>=24.9.0` | Node 版本下界 |
| `patchDirectory` | `patches/dsh-v0.2.2-rc.1` | 补丁目录 |
| `patchedSourceSha256` | `[sha256]` | 打补丁后源码摘要 |
| `maintenanceSource` | `patches/dsh-v0.2.2-rc.1/source.json` | 维护清单 |

## 版本与兼容性

| 项 | 值 | 说明 |
| --- | --- | --- |
| 产品 schema | `1` | 新增必填键是破坏性变更 |
