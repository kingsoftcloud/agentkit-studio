## Four configuration files

Studio has no environment-variable configuration surface; everything lives in these four files. Changing configuration is changing code and goes through the same review.

| File | Purpose | Schema |
| --- | --- | --- |
| `src/product.json` | Product identity, copy and desktop packaging input | `1` |
| `studio.plugin.json` | Plugin manifest: version, Host requirements, capabilities, contributions | — |
| `dsh-pin.json` | DSH base pin: version, commit, patch directory | `1` |
| `cordis.patch.yml` | Enable, disable or insert modules on top of the official DSH base | — |
