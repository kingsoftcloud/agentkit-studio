## Three tiers

Studio reads 130 environment names from the process environment: 8 through a direct `process.env.X` read, the rest through an injected `env` parameter or a `*_ENV_NAMES` constant array.

| Tier | Identifier | Count | Meaning |
| --- | --- | --- | --- |
| Configurable | `configurable` | 34 | Operators and developers may set these; unset means the code default applies. |
| Platform-injected | `platform` | 84 | Injected by the container, managed runtime or desktop shell; manual values are usually overwritten or ignored. |
| Do not set | `forbidden` | 12 | Studio reads these, but the value must come from the credential service or settings UI; never write them into a shell profile, `.env` or CI variable. |

<Callout type="warn" title="Credentials come from the settings UI only">
Names in the "Do not set" tier are owned by the credential service or settings UI. Writing them into a shell profile, `.env` or CI variable bypasses the Studio credential boundary and leaks them into logs.
</Callout>

## Common settings

| Variable | Default | Purpose |
| --- | --- | --- |
| `AGENTKIT_HOME` | `~/.agentkit` | Studio data directory: grants, caches, cloud Skills |
| `DSH_HOME` | `~/.dsh` | DSH host directory; point it at a temp directory when developing |
| `DSH_AGENTS_HOME` | `~/.agents` | Root for native Tools that resolve an Agent directory |
| `AGENTKIT_STUDIO_DSH_PLUGIN_INDEX` | empty | HTTPS address of a remote plugin index; empty means builtin only |
| `AGENTKIT_EXECUTION_POLICY_DEFAULT` | `workspace-write` | Default execution policy for a new Agent |
| `AGENTKIT_EXECUTION_POLICY_MAX` | `workspace-write` | Highest execution policy an Agent may request |
| `AGENTKIT_STRICT_RESOURCES` | empty | Truthy fails on a missing resource instead of degrading |
| `AGENTKIT_PROMPT_PREDICTION_ENABLED` | empty | Enables prompt prediction |
| `CODEX_HOME` | `~/.codex` | Codex App Server home |
| `OPENAI_BASE_URL` | empty | OpenAI-compatible endpoint; injected by the platform in container deployments |

Source is authoritative for every default; the Default column only repeats the fallback the code actually reads.
