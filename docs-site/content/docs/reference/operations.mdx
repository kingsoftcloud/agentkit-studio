## 退役与仅契约的 id

有 21 个 id 仍然保留在契约里，但 Host 分发会直接抛 `STUDIO_LEGACY_HARNESS_RETIRED`（`src/host/routes/sessions.mjs:8`）。这是**故意的**：老客户端拿到可识别的错误码，而不是 404。



<Callout type="warn" title="不要依赖退役 id">
`sessions/native-*` 属于已移除的进程内 Harness。新集成请改用对应运行时的原生会话接口，见[会话事件](./session-events.mdx)。
</Callout>

## 版本与兼容性

| 项 | 值 | 说明 |
| --- | --- | --- |
| operation id 数 | `147` | 新增或删除都是破坏性变更 |
