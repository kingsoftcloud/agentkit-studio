## Field constraints

`validateTeamTemplate()` is the only entry point. The limits below are extracted from the `requiredText` / `optionalText` calls in the validator, so they share one source.

| Field | Limit | Unit |
| --- | --- | --- |
| `instructions` | 16000 | chars |
| `roles[].instructions` | 8000 | chars |
| `roles[].template.id` | 256 | chars |
| `roles[].template.digest` | 256 | chars |
| `roles[].model / defaultModel` | 256 | chars |
| `id` | 128 | chars |
| `name` | 120 | chars |
| `roles[].label` | 80 | chars |
| `roles[].template.version` | 64 | chars |
| `roles[].name` | 64 | chars |

Additional format constraints:

| Field | Type / pattern | Constraint |
| --- | --- | --- |
| `kind` | `"team"` | Fixed value; anything else is rejected |
| `id` | `^[a-z][a-z0-9-]*$` | Lowercase letter first, then lowercase letters, digits and hyphens |
| `version` | `^\d+\.\d+\.\d+$` | Strict three-part semver |
| `roles` | array | 2–9 roles; `roles[0].name` must be `lead` |
| `roles[].name` | `^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$` | Hyphen-separated and unique across roles |
| `roles[].template.version` | semver | Falls back to the team `version` |

## Rejected shapes

| Input | Rule | Fix |
| --- | --- | --- |
| `roles[].agentId` | A role cannot reference a plain Agent | Use an immutable `template` reference |
| `roles[].source.kind` | Rejected when the value is `agent` | Same as above |
| `subAgents` / `sub_agents` | A role cannot declare a nested subagent | Compose roles at the team level |
| `roles[].template` | Missing `id` or `digest` | Add the content lock |
| Placeholder model | `one-team-model` | Must be replaced with a real model profile |
| `runtime.type` | `dsh-native` · `harness` | Only these runtimes are accepted |
