## Catalog document shape

The plugin market catalog schema version is `1`. A remote index is a JSON document: either an array, or an object `{ schemaVersion, plugins, updatedAt }`.

```json
{
  "schemaVersion": 1,
  "updatedAt": "1970-01-01T00:00:00Z",
  "plugins": [
    {
      "id": "@scope/dsh-plugin",
      "displayName": "Example plugin",
      "category": "Collaboration",
      "tags": [
        "team"
      ]
    }
  ]
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `schemaVersion` | `number` | Defaults to 1; any other value is rejected |
| `plugins` | `array` | Rows, capped at 500 |
| `updatedAt` | `string` | ISO timestamp; dropped when unparsable, without affecting rows |

## Index address and merging

| Item | Value |
| --- | --- |
| Environment | `AGENTKIT_STUDIO_DSH_PLUGIN_INDEX` |
| Aliases | `DSH_PLUGIN_INDEX_URL` |
| Protocol | `https:`; `http:` only for `localhost` / `127.0.0.1` / `::1` |
| Rejected | URLs with a username or password, non-HTTP(S) schemes, unparsable URLs |
| Merge | Builtin rows reserve the id; a remote row overrides copy fields but not readiness fields; new ids append |
| Failure | A failed refresh keeps the last good document as stale; the market never empties |
