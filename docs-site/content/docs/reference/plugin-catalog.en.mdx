## Catalog document shape

| Field | Type or value | Notes |
| --- | --- | --- |
| `format` | `1` | DSH index format version |
| `title` | `string \| object` | Index name, optionally localized |
| `metadata.sortKeys.downloads` | `object` | Download-count sort definition in the bundled index |
| `plugins` | `array` | Plugin entries, each with a unique npm package name |
| `plugins[].versions` | `array` | Each entry has an exact SemVer, publication time and installation source |

## Default index source

Studio serves its bundled community index at `/api/agentkit.plugin-market/index.json`. Studio adds it only when the DSH profile has no configured indexes. The DSH plugin market fetches, validates, searches and pages the index. The bundled snapshot contains 80 plugins and is refreshed through Studio releases.

## Independent Star Harness releases

The Star Harness management page discovers installable versions through a signed release manifest. Studio checks host compatibility and verifies the engine, renderer and tool catalog before activation. The community index provides general DSH plugin browsing.
