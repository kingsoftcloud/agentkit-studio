## Command entry points

Two execution surfaces: 56 `Makefile` targets (default `check`) and 106 check scripts under `scripts/`.

| Entry | Count | When to use |
| --- | --- | --- |
| `make <target>` | 56 | Daily development, packaging and gates; targets carry prerequisites and platform checks |
| `node scripts/verify-*.mjs` | 106 | Single checks; the gate targets call these internally |
| `node scripts/*.mjs` | 216 | Build, release and codegen scripts, not checks |

<Callout type="info" title="Read the prerequisites">
Most targets have prerequisites (for example `web-dev` depends on `profile-install`). Running the dependency chain beats typing commands in order by hand.
</Callout>

## Platform support

Desktop builds ship for macOS arm64 and Windows x64 only. Another 2 legacy Intel-Mac targets in the repo are outside the supported path, so they are absent from the list below.

| Platform | Architecture | Status |
| --- | --- | --- |
| `macOS` | `arm64` | Supported, ships a `.dmg` |
| `Windows` | `x64` | Supported, ships an NSIS `.exe` |
| `macOS` | `Intel` | **Not supported**; appears in neither the docs nor the release artifacts |
