## How codes are counted

199 codes in total: 194 from `code: '...'` literals under `src/**` and 5 from the wire boundary (`STUDIO_WIRE_ERRORS`); the sets overlap and are unioned.

A code is a **stable contract**: it appears in client branches, logs and triage docs. Renaming one is a breaking change.
