## Transport rules

The control channel is fixed at `/agentkit`: 146 operation ids across 26 domains.

| Rule | Value | Source |
| --- | --- | --- |
| Control channel | `/agentkit` | `src/contracts/operations.mjs:155` |
| Request envelope | `{ operationId, payload }`; the payload must be serializable JSON | `src/contracts/wire.mjs` |
| Response envelope | `{ ok: true, value }` or `{ ok: false, error }` | `src/contracts/wire.mjs` |
| Cancellation | Fourth argument is an `AbortSignal`; one terminal envelope, no retry of unknown effects | `src/contracts/definitions.mjs:8` |
| Idempotency | `list` / `get` / `status` / `*.history` are read-only; everything else follows its operation semantics | — |

## Retired and contract-only ids

21 ids stay in the contract, but Host dispatch throws `STUDIO_LEGACY_HARNESS_RETIRED` (`src/host/routes/sessions.mjs:8`). This is **intentional**: old clients get a recognizable code instead of a 404.



<Callout type="warn" title="Do not depend on retired ids">
`sessions/native-*` belongs to the removed in-process Harness. New integrations should use the native session API of the matching runtime; see [Session events](./session-events.mdx).
</Callout>
