## 三档口径

Studio 从进程环境读取 154 个变量名：其中 8 个是直接 `process.env.X` 读取，其余经注入的 `env` 参数或 `*_ENV_NAMES` 常量数组转发。

| 档位 | 标识 | 条数 | 含义 |
| --- | --- | --- | --- |
| 可配置 | `configurable` | 55 | 运维或开发者可以显式设置，未设置时走代码默认值。 |
| 平台注入 | `platform` | 89 | 由容器、托管运行时或桌面外壳注入，手工设置通常会被覆盖或不生效。 |
| 禁止修改 | `forbidden` | 10 | Studio 会读取，但值必须由凭证服务或设置界面持有；不要写进 shell profile、`.env` 或 CI 变量。 |

<Callout type="warn" title="凭证只从设置界面写入">
标为「禁止修改」的变量由凭证服务或设置界面持有。把它们写进 shell profile、`.env` 或 CI 变量会绕过 Studio 的凭证边界，并在日志中出现。
</Callout>

## 常见配置

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `AGENTKIT_HOME` | `~/.agentkit` | Studio 数据目录：授权、缓存、云 Skill |
| `DSH_HOME` | `~/.dsh` | DSH 宿主目录；开发时建议指到临时目录 |
| `DSH_AGENTS_HOME` | `~/.agents` | 原生工具解析 Agent 目录的根 |
| `AGENTKIT_EXECUTION_POLICY_DEFAULT` | `workspace-write` | 新建 Agent 的默认执行策略 |
| `AGENTKIT_EXECUTION_POLICY_MAX` | `workspace-write` | 允许 Agent 申请的最高执行策略 |
| `AGENTKIT_STRICT_RESOURCES` | 空 | 设为真值时资源缺失直接失败，而不是降级 |
| `AGENTKIT_PROMPT_PREDICTION_ENABLED` | 空 | 开启下一句提示 |
| `CODEX_HOME` | `~/.codex` | Codex App Server 的 home |
| `OPENAI_BASE_URL` | 空 | OpenAI 兼容端点，容器部署时由平台注入 |

完整默认值以源码为准；本表的「默认值」列只写代码里能读到的回退值。
