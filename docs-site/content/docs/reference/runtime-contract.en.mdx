## Contract version

The runtime contract has exactly one version constant: `agentkit.studio.runtime/v1`. It gates the Agent form, portable runtime bundles and deployments alike.

| Constant | Value | Meaning |
| --- | --- | --- |
| `STUDIO_RUNTIME_CONTRACT_VERSION` | `agentkit.studio.runtime/v1` | Contract version and admission gate |
| `STUDIO_RUNTIME_TYPES` | `dsh-native` · `harness` · `codex` | Publicly routable runtime types |
| `STUDIO_CANONICAL_IDENTIFIERS` | `agentId` · `revision` · `buildId` · `sessionId` · `runId` | Identifier field names shared by every entity |

**There are 3 public runtimes**: `dsh-native`, `harness`, `codex`. `assertStudioRuntimeType()` accepts only these and rejects everything else with `RUNTIME_UNSUPPORTED`. Adding a runtime only changes `src/runtime-contract.mjs:STUDIO_RUNTIME_TYPES`; this page's count and capability matrix follow automatically. See [runtimes](../concepts/runtimes.mdx).

## Entities and identifiers

## Validation errors

| Code | Trigger | Source |
| --- | --- | --- |
| `RUNTIME_UNSUPPORTED` | `runtime.type` is neither public nor experimental | `src/runtime-contract.mjs:67` |
| `RUN_IDENTITY_INVALID` | `agentId` / `sessionId` / `runId` / `buildId` missing, or `revision` is not a positive integer | `src/runtime-contract.mjs:74` |
| `RUN_IDENTITY_MISMATCH` | Run identity disagrees with the bound route | `src/runtime-contract.mjs:88` |

`studioRunIdentity()` normalizes before validating, so a blank string equals a missing field; `revision` is coerced to a number.
