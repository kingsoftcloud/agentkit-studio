## 目录文档结构

| 字段 | 类型或值 | 说明 |
| --- | --- | --- |
| `format` | `1` | DSH 索引格式版本 |
| `title` | `string \| object` | 索引名称，可提供多语言文本 |
| `metadata.sortKeys.downloads` | `object` | 内置索引的下载量排序定义 |
| `plugins` | `array` | 插件条目，每项使用唯一的 npm 包名 |
| `plugins[].versions` | `array` | 每项包含精确 SemVer、发布时间与安装来源 |

## 默认索引源

Studio 将内置社区清单暴露在 `/api/agentkit.plugin-market/index.json`。仅当 DSH 的配置中尚无索引时，Studio 才添加此默认源。DSH 的插件市场负责读取、校验、搜索和分页。清单目前包含 80 个插件，随 Studio 发版更新。

## Star Harness 独立发行

Star Harness 管理页通过签名发布清单发现可安装的版本。Studio 校验宿主兼容性以及引擎、界面与工具目录的完整性，再激活对应版本。社区索引负责 DSH 的通用插件浏览。
