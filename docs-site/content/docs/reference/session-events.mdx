## 顺序与配对

```text
turn/start → request/header → request/context → step/start
  → assistant/attempt → (tool/call → approval/asked → approval/decided → tool/result)*
  → step/end → assistant/message → turn/end
```

| 事件 | 顺序规则 |
| --- | --- |
| `turn/start` | 一轮的唯一起点。 |
| `turn/end` | 唯一保证出现的终止事件；缺失表示连接中断。 |
| `step/start` | 一个 step 内至少一次 `assistant/attempt`。 |
| `step/end` | 与 `step/start` 一一配对。 |
| `system/message` | 可出现在任意位置，不改变轮次状态。 |
| `request/header` | 紧跟 `turn/start`，每轮一次。 |
| `request/context` | 紧跟 `request/header`。 |
| `user/message` | 通常在一轮开头出现一次。 |
| `assistant/message` | 每轮最多一条，取最后一次尝试。 |
| `assistant/attempt` | 重试时同一轮会出现多条。 |
| `tool/call` | 按调用 id 与 `tool/result` 配对。 |
| `tool/result` | 必须在对应的 `tool/call` 之后。 |
| `approval/asked` | 只在工具需要授权时出现。 |
| `approval/decided` | 必须与 `approval/asked` 配对。 |
| `agent/inbox/spliced` | 表示并发写入，投影需按序合并。 |
| `agent-preset/selected` | 通常出现在一轮开始之前。 |
