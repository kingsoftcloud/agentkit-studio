## 这一章是什么

这里是 AgentKit Studio 的**机器可读契约**：枚举值、字段名、错误码、operation id、环境变量与命令。本页所有数字都由 `docs-site/scripts/extract-reference.mjs` 从源码抽取，没有一个是手写的。

```sh
cd docs-site
node scripts/extract-reference.mjs          # 重新生成 22 个页面
node scripts/extract-reference.mjs --check  # CI：源码改了但页面没重生成就失败
```

改动 `src/` 里的枚举、错误码或 operation 列表后，必须重跑脚本；否则 `--check` 会让 CI 失败。
