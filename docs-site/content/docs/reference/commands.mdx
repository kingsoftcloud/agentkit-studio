## 命令入口

仓库有两个执行面：`Makefile` 的 56 个目标（默认目标 `check`），以及 `scripts/` 下的 100 个校验脚本。

| 入口 | 条数 | 什么时候用 |
| --- | --- | --- |
| `make <target>` | 56 | 日常开发、打包、门禁；目标带依赖与平台检查 |
| `node scripts/verify-*.mjs` | 100 | 单点校验；门禁目标内部也是调它们 |
| `node scripts/*.mjs` | 204 | 构建、发布、代码生成等非校验脚本 |

<Callout type="info" title="先看依赖">
`make` 目标大多有前置依赖（例如 `web-dev` 依赖 `profile-install`）。直接跑依赖链比手动按顺序敲命令安全。
</Callout>

## 平台支持

桌面端只发布 macOS arm64 与 Windows x64 构建。仓库里另有 2 个面向 Intel Mac 的遗留目标，不属于受支持路径，因此不在下面的清单里。

| 平台 | 架构 | 状态 |
| --- | --- | --- |
| `macOS` | `arm64` | 受支持，发布 `.dmg` |
| `Windows` | `x64` | 受支持，发布 NSIS `.exe` |
| `macOS` | `Intel` | **不受支持**，文档与发布物里都不出现 |
