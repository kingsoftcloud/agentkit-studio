## 错误码口径

共 197 个错误码：192 个来自 `src/**` 的 `code: '...'` 字面量，5 个来自 wire 边界的 `STUDIO_WIRE_ERRORS`（两者有重叠，取并集）。

错误码是**稳定契约**：它出现在客户端分支、日志与排障文档里，改名就是破坏性变更。
