**This page is the only correct spelling of every AgentKit Studio term. One concept has exactly one name; API field names, enum values, and error codes are never translated.**

Terms are grouped by theme. To find where a term is explained in full, see the last row of each group.

## Naming rules

| Rule | Meaning |
| --- | --- |
| Chinese first | Chinese prose gives Chinese with English in parentheses on first use, then Chinese only |
| English first | English pages invert it: English with Chinese in parentheses, then English only |
| Never translate | API field names, enum values, and error codes stay verbatim |
| One name | Where a concept has historical aliases, only the name listed here survives |

## Entities and lifecycle

| Chinese | English | Code / value | One-sentence definition |
| --- | --- | --- | --- |
| 智能体 | agent | `agentId` | A reusable capability configuration that holds only a pointer to its current revision. |
| 修订版本 | revision | `revision` | An immutable snapshot of an agent, with the sequence number incremented on every save. |
| Agent 构建 | build | `buildId` | A content-addressed runnable package that freezes one revision. |
| 构建产物 | bundle | `agent-bundle.zip` | The ZIP a build produces, always containing the manifest, the spec, and a readme. |
| 会话 | session | `sessionId` | A durable event journal owned by DSH; Studio never writes it. |
| 一次运行 | run | `runId` | One turn, from `turn/start` to `turn/end`. |
| 预设 | preset | `agentkit-studio-agent-…` | The name under which a revision is registered in the DSH run registry. |

## Runtimes and execution

| Chinese | English | Code / value | One-sentence definition |
| --- | --- | --- | --- |
| 运行时类型 | runtime type | `runtime.type` | The value that decides whose execution model serves a run. |
| DSH 原生 | DSH Native | `dsh-native` | The default runtime, executed by DSH itself. |
| Star Harness | Star Harness | `harness` | The runtime executed by the KSADK Harness native kernel. |
| Codex | Codex | `codex` | The runtime executed by the Codex App Server adapter. |
| 执行策略 | execution policy | `read-only` / `workspace-write` / `danger-full-access` | The three-tier policy limiting where a run may write; default `workspace-write`. |
| 权限模式 | permission mode | `permissionMode` | The execution-policy entry describing write scope. |
| 审批策略 | approval policy | `ask` / `never` | Whether to stop and ask when an action needs confirmation. |
| 原生权限策略 | native agent policy | `strict` / `loose` / `custom` | An extra tool constraint on a Star Harness agent; tightens only, never grants. |
| 冻结运行时 | frozen runtime | — | Configuration locked at build time that the runtime may only obey. |
| 无人值守执行 | unattended execution | — | A run with nobody available to approve; always read-only. |

## Sessions, workspaces, and events

| Chinese | English | Code / value | One-sentence definition |
| --- | --- | --- | --- |
| 工作区 | workspace | — | The directory a session is bound to, which sets the write boundary. |
| 会话事件 | session event | 16 kinds | The standard events in a DSH session journal. |
| 流帧 | stream frame | `start` / `chunk` / `end` | In-process delta frames never written to the durable journal. |
| 瞬时帧 | transient frame | `assistant/live-chunk` | A client-only typewriter delta carrying a fractional sequence number. |

| 序号 | sequence | `seq` | A monotonically increasing event position within a session. |
| 会话契约 | session contract | `p1-session-contract-v0.1` | The version identifier of the session boundary between Studio and DSH. |
