## What the product does

<Cards>
  <Card title="Agent authoring">Multi-step form, immutable revisions, frozen runtime configuration.</Card>
  <Card title="Three runtimes">DSH Native, Star Harness, and Codex, with an explicit capability matrix.</Card>
  <Card title="Resource bindings">MCP servers, skills, knowledge bases, and memory bound to a revision.</Card>
  <Card title="Cloud deployment">24×7 managed runtimes with 19 observable, rollback-able deployment states.</Card>
  <Card title="Experts and teams">Expert templates and local teams sharing the same revision semantics.</Card>
  <Card title="Plugin ecosystem">DSH plugin market, Codex plugins, remote index, and readiness checks.</Card>
</Cards>
