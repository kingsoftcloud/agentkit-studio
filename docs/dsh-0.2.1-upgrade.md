# DSH 0.2.1-rc.2 升级

## 目标与边界

Studio 直接使用官方 `dsh-v0.2.1-rc.2`，固定提交 `687f282e8625c6b8d11ff58211a90524be2e4317`。插件依赖、Host API、构建、CI 和维护源码统一到这一版本，不提供旧 DSH 运行时回退。旧补丁和维护归档只用于发布追溯，不进入当前构建。用户配置、Agent 定义和持久会话仍须保留。

官方变更说明：[rc.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.1)、[rc.2](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.2)。以下处理依据固定源码及 Studio 的实际调用，不代表所有新增实验功能都默认开启。

## 两个实际报错

安装的 `.20261016.6` 缺少 `app-update.yml`，来自此前预览包手工装配时漏写更新源。修复落在交付流程：先由产品设置生成更新源，签名前写入，签名后核对；同时修正 Mac 指向旧 DSH 发布目录的问题；缺失或地址/通道/架构错误均阻止交付。已安装的旧包无法通过缺失的更新源自我修复，需要安装修复后的包。

个人助理是另一个问题。实际读取 Bootstrap：当前线上区域没有 Studio 镜像目录及容器持久化能力声明；预发两项都有。按本次确认只用隔离预发配置验证，保留用户的线上配置；不把预发镜像冒充线上版本。客户端错误会显示环境和区域，并提供云端设置入口。

- 真实当前 Host：14 项运行、MCP 工具续接、持久会话恢复、指纹重试/取消及插件卸载检查通过，使用受控本地模型。另用 `scripts/verify-studio-team-host.mjs` 验证团队创建、角色冻结、官方成员启动、Inbox 报告送达及主理人汇总。
- 预发个人助理：隔离配置完成真实云端开通、模型问答、绑定记忆写入及读回；异步记忆提取完成后确认落库，再删除本次记忆探针及自建云端实例。共享记忆库和用户原有线上配置保留。预发入口使用内部 CA，仅在隔离验证进程加载从已认证集群核对的证书链，证书校验保持开启；这不代表普通安装环境已具备该 CA 信任。

- 公共更新 feed 当前返回 404。修复后的本地候选包必须另行完成发布与原生更新验收，不能把内置更新源或签名检查等同为自动更新恢复。Windows 原生安装更新和线上部署不在本次已完成证据内。
