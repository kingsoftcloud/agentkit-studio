# 创建与部署页面验收（2026-10-09）

本轮针对创建入口、部署页面和控件辨识度；真实浏览器运行于固定 DSH 0.2.0-rc.2 宿主。

## 创建与绑定

- Agent 页面仅保留“对话创建”和“手动配置”。手动配置的模板默认收起；输入自定义提示词后切换模板，没有覆盖自定义内容。
- 浅色、深色及 760 px 窄窗口检查通过，输入框和卡片边界可辨识，主内容无横向溢出。
- 对话创建进入新的未分组原生会话，没有工作区和旧 Agent 绑定，保留默认模型；只填入引导语，不自动发送。
- 真实模型调用依次产生草稿 Revision 1、Revision 2。修改名称和输出规则后仍为草稿，明确确认后才创建本地 Agent。
- 将新 Agent 绑定到无工作区原生会话，输入会议记录，未在用户消息中提示身份或指定输出标题。回答遵循系统提示词的三个固定标题，缺失负责人和日期标记为待确认。
- 原生会话“创建 Agent”按钮也进入新的未绑定会话，不携带当前 Agent 身份；最终引导语包含每轮最多两个关键问题，该问句数量仅为提示词要求，未作为强制协议验收。
- 验收创建的临时 Agent 已通过页面删除，保留会话历史供核对。

## 构建与部署

- 页面按选择 Agent、选择成功构建、检查并部署组织；默认选择最新成功构建，历史默认收起。
- 默认规格为 2 核 4 GB。切换到 1 核 2 GB 后完成真实 KOP 部署预检查，显示预发环境、冻结版本和已核验的子账号操作人。
- 更改规格使旧预检查确认失效；本轮没有提交云端创建，不能据此宣称 1 核 2 GB 实例已实际启动。
- 当前 Agent、全部 Agent、已删除历史、分页和详情展开已检查；其他 Agent 的未知创建结果仍可发现，并仅提供核对入口。
- 快速切换 Agent 和晚到预检查响应的隔离由行为测试验证。
