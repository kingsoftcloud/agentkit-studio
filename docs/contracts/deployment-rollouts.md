# 云端版本升级与回滚

运行中心选择冻结 Build 后，已有就绪部署可使用“升级到所选构建”。完成过升级的部署可选择
历史版本并“检查回滚”。检查阶段核对原子账号、镜像目录、私有 ZIP 摘要和所有资源凭证，
展示目标版本后才提交。升级不改变云端 Agent ID、运行时、区域和实例规格。

Host 保存不可变创建意图、成功版本和每次切换意图。回滚下载该历史版本的原始 ZIP，
不会重新导出当前资源；凭证从现有配置重新解析，不存入版本历史。已移除或变更地址的
资源可能阻止回滚，此时须恢复对应配置，不能用新资源静默替代历史绑定。

写入沿用 `UpdateAgent(ContainerConfig, EnvironmentVariablePatch)`。仅清理旧冻结包声明且
新包不再需要的变量，保留平台注入的账号凭证。上传和更新各自只有一次持久化执行声明；
超时或 Host 重启后，不因重复点击自动再次提交云端更新。提交前中断可通过刷新确认旧版本
后重新检查；提交后结果不明需等待控制面和运行入口核对，或删除已确认来源的测试实例。

镜像目录的 `runtimeIdentity: true` 表示包含鉴权 `GET /v1/agentkit/runtime` 合同。旧镜像未
声明时，检查阶段拒绝作为升级或回滚目标。版本探测返回 Agent、Build、ZIP SHA256 和
`deploymentVersion`；后者来自此次更新注入的唯一切换标识。即使只换镜像、ZIP 不变，旧
实例也不能通过。控制面必须显示 RUNNING、存在就绪副本，且入口返回完整匹配身份，才标记
READY。探测不调用模型，不创建会话，不能用网关 `/health` 成功替代。

云端目录投影当前成功版本，旧版本的原生会话预设保留用于历史显示。切换期间不接受新运行；
成功后，之前绑定的会话明确提示开启新会话。已升级部署每次连接还核对运行入口身份。

镜像启动器可传 `--versioned-state`，在状态根的 `versions/<ZIP SHA256>` 下分别保留冻结包
及 DSH 历史，回滚不会删除旧目录。原单包模式继续拒绝覆盖。目录隔离与本地测试不是持久卷
验收；平台仍须提供持久卷，跨副本、容器重建和实际云端升级另行验收。

## 验证边界

合同测试覆盖三种运行时的原实例更新/回滚、旧 Pod 拒绝、平台更新中不误报、移除 MCP
凭证且保留平台凭证、凭证切换拒绝、旧镜像拒绝、重复请求与未知更新结果的重启恢复。
真实云端与页面验收结果在对应的日期记录中单列，不以这些模拟测试代替。
