# 记忆召回验收结论（2026-10-08）

用户确认“记忆召回这个你可以算通过了”。本轮记忆召回按该确认结项，不再作为当前交付的
阻塞项。用户给出的预期是异步记忆提取和召回约需 20 秒，而非写入回答完成后立即可查询。

已取得的自动化证据：真实云端 CreateMemorySdk 接受写入后，在隔离的 Agent/User 范围中
等待 25 秒，QueryMemorySdk 返回新记忆；ListSessions 显示提取完成，ListMemories 中也能
找到目标内容。检验的是实际 Memory 字段，不能将接口返回的查询文本回显当作召回命中。

此前多个运行时共用一个验收 Agent 并反复写入相似订单号，旧范围出现返回旧值、未召回新值的
记录。隔离范围复测通过，不等于已修复服务端旧范围的数据提取或归并问题；历史失败记录仍
保留。模型回答“已记住”和写入接口接受任务均不单独作为持久化成功证据。

本确认仅关闭记忆召回验收项，不扩大为 Linux 命令沙箱、正式 DMG 签名、公证或预发部署
生命周期通过。这些项目保持各自的验证边界。
