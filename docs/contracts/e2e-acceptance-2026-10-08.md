# Agent 列表与无工作区会话验收

日期：2026-10-08。沿用固定 DSH v0.2.0-rc.2、官方 Host 与原生会话页。

## 本轮结果

- 本地、云端 Agent 独立分页和搜索；本地目录不请求云端。真实页面分别显示 14 个本地、16 个云端 Agent，创建时间倒序。最新的本地 Agent 出现在首行。重复点击已选 Tab 不清空列表。
- 原生会话提供“新建无工作区会话”。从已绑定 Agent 的工作区空白会话进入后，未选文件夹即可发送，Agent 和 glm-5.3-flash 模型保持；返回原工作区空白会话，未发送草稿仍在。
- DSH Native 盲测仅提交普通苏州行程问题，返回只存在于系统提示词的标记 RIVER-29、两天行程和 budget=800，5 秒完成。
- 自研 Harness 从“草稿”Agent 直接绑定并对话，没有创建 Build。普通杭州行程问题返回专有标记 PINE-73、两天行程和 budget=600，2 秒完成。
- 资源准入移到 Session 创建之前，MCP 探测失败不再先留下空白 Session；未放宽资源校验。
- `make release-check`：364 项通过，包完整性 215 个文件通过。声明的 Node 22.19.0 上目录、Server client 和构建操作 34 项通过；加入准入失败不创建 Session、无 Agent 的工作区可选入口及重复点击 Tab 回归测试后，`make check` 最终 367 项通过。
- 左下角设置入口的展开、折叠、键盘和原生模型设置页已验收；新版只增加 DSH Native、Codex、自研 Harness 的能力，保留控制面已有其他框架的目录记录。

本机网页截图在忽略目录 `.artifacts/`：`e2e-agent-tabs-20261008.png`、`e2e-workspace-free-blind-20261008.png`、`e2e-unbuilt-agent-chat-20261008.png`。
