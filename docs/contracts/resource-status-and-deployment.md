# 资源状态、删除与部署边界

## 目录状态

Skill 的原始 `ready` 表示本地导入目录包含可读取的 Skill 文件；`available` 来自云端
Skill Space 目录。页面分别显示“本地已导入”和“云端目录可见”。这两种状态都不是执行
认证：脚本依赖、资源权限和实际模型调用必须另行验收。云端 Skill Space 在运行准入时由
Host 下载并加载；本地文件预览仅针对本地导入记录。

MCP 的“已配置，未探测”表示仅保存连接配置；“探测通过”表示最近一次连接和 tools/list
成功；“云端运行中”是服务端状态。探测失败保留错误码。任何目录状态均不能证明每个
tools/call 或整个 Agent 任务已经通过。

## MCP 删除

本地“移除配置”只移除本机连接记录，不删除远端 MCP 服务。云端“删除云端 MCP”由 Host
调用已有 `DeleteMCP` Action，参数为 `Id`，沿用当前账户、区域和认证配置；服务端会软删除
资源并清理关联运行时。确认弹窗明确说明影响范围。

Host 必须收到显式 `scope: cloud` 才允许云端删除；本地记录不存在时禁止自动回退到云端。
只有 `Data.Deleted === true` 才报告删除成功。失败不自动重试，已有 Agent Revision 不会被
静默修改；引用已删除资源的 Agent 需要在编辑页更新绑定。

## 本机运行与预发部署

本地真实验收涵盖 MCP 搜索与读取、本地和云端 Skill 脚本、知识检索、跨会话记忆与 Agent
隔离，以及组合绑定。样例证据见 [端到端验收矩阵](e2e-acceptance-2026-10-07.md) 的 R02–R08。
它们不表示目录中所有资源、全部运行时组合或预发环境已经验收。

冻结 Build 保留 Prompt、Agent Revision 和绑定引用，**不等同于把资源本身打包进产物**。

| 绑定 | 目标环境需要的条件 |
| --- | --- |
| 本地 Skill | 分发完整 Skill 文件及脚本依赖，使用可移植路径并校验内容 |
| 本地 MCP 配置 | 注入连接配置和凭证引用；目标环境可访问 Endpoint |
| 云端 MCP / 知识库 / 记忆库 / Skill Space | 目标账户、区域、权限、网络与引用一致或完成映射；记忆隔离标识也需保持一致 |
| 模型 | 目标 Host 能解析绑定的模型配置并获得独立注入的凭证 |

当前 [冻结 Build HTTP 入口](frozen-build-runtime.md) 仍运行在已配置的 Studio Host 上，
尚未打通可携带运行产物、资源和凭证注入、上传、云端部署与 Server `/v1/responses` 协议
适配。部署后的绑定效果未验收，不能承诺直接部署后自动保留本机行为。凭证不得写入 Build ZIP。
