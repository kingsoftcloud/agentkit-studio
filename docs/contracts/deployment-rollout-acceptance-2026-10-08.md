## 实测发现并修复

首次升级后，新建会话也被错误拒绝为旧版本。原因是 preset 已包含 `cloudVersionId`，
但 Studio 保存 DSH `agent/request` 路由和进入 Host LLM waterfall 时没有传递该字段。
补齐两个边界后，新会话正确使用新版本，旧会话仍不能静默跨版本运行。

新增回归测试从实际 preset 注册、运行插件的 scoped request 到 Host waterfall 和云端
对话适配器贯通三个版本，覆盖相同 Agent Revision 下的升级/回滚；先复现失败再修复。
本轮 `make release-check` 通过 485 项测试、18 个补丁格式检查；补入验收文档后，293 个跟踪文件的路径检查和 286 文件的包完整性复查通过。
