# 专家目录与本地团队

智能体页面提供“我的智能体”和“模板广场”。内置目录仅包含原创模板；创建后的专家使用现有 Agent Store、Revision、资源绑定、Build 和原生 DSH 会话。

模板广场提供专家、专家团、技能和连接器。全新配置默认读取所选环境的 Server 目录；未配置云端凭据或 Server 暂时不可用时，读取 Server 导出的公开 KS3 目录快照。预发和线上共用公开 bucket，并使用独立目录前缀。远端目录使用不可变版本和摘要；资源按需下载并验证，离线时回退到缓存或内置模板。账号凭证仍由本机 Host 凭证服务管理，模板环境不会改变知识库、记忆库或部署的资源环境。导入内容保留来源与许可，资源包不随安装包发布。维护与发布流程见 [公开模板分发](public-template-catalog.md)。

“召唤”先检查模型与资源需求，再创建普通 Agent 并打开原生会话。缺少知识库、记忆库或 MCP 授权时需要用户补齐。模板只声明资源需求，不复制作者的资源标识或授权。自定义创建和后续编辑继续使用同一编辑器。

本地专家团复用固定版本的官方 Agent Teams。成员支持本机 DSH Native 和 Harness；Codex、云端成员和团队云部署不在当前范围内。每次运行冻结团队及专家版本，保留完整提示词与绑定；后续修改不改变已有运行。主理人与成员会话、共享任务、消息和恢复由 DSH 管理。团队页可查看状态、进入原生会话或停止运行。

界面模块位于 `src/client/pages/`；Host 的模板服务、路由和操作注册表分别位于 `src/host/services/templates.mjs`、`src/host/routes/templates.mjs` 和 `src/contracts/operations.mjs`。模板任务及其下载会随所属 Host 卸载而取消。侧栏会话列表仍完整复用 DSH，选择 Agent 不会过滤历史列表。

模板导出仅导出定义，不会自动公开或发布内容。外部服务可用性、第三方内容许可和真实云端运行需要各自验证。
