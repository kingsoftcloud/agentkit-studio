# 云端个人助理 MVP

Studio 的「个人助理」侧栏连接一个专属的 DSH Native 云端部署。模型、云端资源、部署凭证、
运行包与持久卷沿用 Studio / AgentEngine 的现有配置；浏览器只保留所选 Agent 与待确认消息，
不接收云端令牌。

未指定对象存储桶时，部署使用 IAM 核验的主账号和目标区域推导默认桶：
`agentengine-{accountId}-{region}`；预发使用实际存储区域，不把环境别名写进桶名。
高级设置可指定其他桶。运行包保存在独立的 `studio-bundles/v1/` 前缀，上传后校验内容摘要和
匿名访问拒绝；不会覆盖插件制品，也不会自动创建桶或修改桶权限。

打开侧栏直接进入对话，输入框固定在底部。只有一个可用助理时自动连接；已有选择时恢复上次的
助理与历史。首次存在多个助理时由用户选择，避免悄悄连接错误的会话。记忆、计划任务与连接选择
放在右上角设置中，打开设置不会重置对话或草稿。Enter 发送，Shift + Enter 换行，输入法组词时不发送。

## 生命周期

云端镜像启用 `personal-assistant/v1` 能力，并提供 Bearer 认证的
`POST /v1/assistant/{operation}`。Studio 先核对部署回执、运行包身份与实时能力，再转发请求。
旧镜像返回需要更新的提示，不会静默降级为随连接断开而取消的执行。

`submit` 调用 DSH Session Controller 的队列接口，并等待 DSH `sessions.flush` 确认保存后
返回 202。请求标识与内容指纹由 DSH 保存；客户端确认结果未知时保留待发送消息，重试使用原标识。
关闭页面或本地 Host 不会取消云端任务，只有明确的 `cancel` 操作会请求停止。
重新连接通过 DSH 历史分页恢复内容，不维护第二份会话数据库。当前面板展示文本消息与定时任务输入，
不展示模型的内部上下文；工具卡片、多模态与完整原生会话呈现仍由后续版本接入。

会话按 Agent、冻结 Build 和会话键寻址。关闭与重新打开相同部署可以恢复；更换 Build 会进入
新的版本状态目录，目前不承诺跨版本迁移。云端实例应使用持久卷和单副本常驻部署；本版本不提供
跨副本调度、故障中任务恰好执行一次或全天候 SLA。

## 定时任务

镜像显式安装并启用 `@deepseek-ai/dsh-experimental-schedule-bundle`。助理的计划、时钟、
持久化、会话恢复和投递复用官方 `schedule` 服务，Studio 只提供当前助理的管理入口。
第一版表单提供延迟一次性任务，执行结果回到原会话。列表中的投递状态不等于模型任务执行成功。

插件运行在云端 Host，因此 Studio 可以退出。安装在桌面 Host 的同一个插件只会随本地 Host 运行。
现有运行中心的 AgentEngine 云端自动化仍保留：它的执行记录、外部投递与平台调度语义不同，
不能直接用单 Host 的会话提醒替换。旧本地自动化暂未迁移或删除；后续迁移需逐条映射计划、保留
停用回执，并验证没有双重触发后移除旧调度器。

## 记忆与积累

绑定记忆库后，沿用既有资源适配器与分区规则。用户可以查看、补充、纠正、删除长期记忆；
修改必须收到云端有效回执，提取异步完成时不能把“已接收”显示为“已记住”。
会话的记忆召回与写入策略沿用 Agent 配置。这里的“进化”指积累并修正事实、偏好和经验，
不包含自动改写程序、扩大权限或自行安装插件。

第一版面向一个专属部署服务一个用户，不能把同一部署令牌分发给互不信任的多个用户。
记忆管理当前最多展示前 100 条；删除长期记忆不会删除原始会话记录。

## 验证

- `tests/personal-assistant.test.mjs`：持久化确认、重复提交、显式取消、会话隔离、记忆归属与旧镜像拒绝。
- `scripts/verify-personal-assistant-host.mjs`：真实构建的 DSH、受控模型、单独终止的客户端进程、官方定时器、磁盘历史恢复。
- 设置 `STUDIO_VERIFY_UI=1` 追加真实 Web Host 与 Chrome 关闭、重开验证。该脚本使用受控云端目录，
  转发到真实 DSH 接口；它不替代 AgentEngine 预发部署与凭证链路的验收。
- macOS 追加 `STUDIO_VERIFY_NATIVE=1` 和 `STUDIO_VERIFY_ELECTRON` 可执行文件路径。
  先用隔离 DSH 的 `tsx` 运行 `scripts/prepare-studio-desktop-dev.mjs`，再把输出的 `primaryRuntime`
  设为 `STUDIO_VERIFY_PRIMARY_RUNTIME`。准备脚本复用官方解释器、Office 资源下载与检查流程；
  `project` 是插件目录，不能作为解释器资源目录。验收启动前检查资源，退出超时会终止自己的 Electron 子进程。
- 最终交付还需预发镜像、真实模型与记忆集成、关闭实际 Studio 后继续执行与恢复的结果。

验证使用独立的 `DSH_HOME`、`AGENTKIT_HOME` 和固定的 `AGENTKIT_DSH_ROOT`；报告与截图保存在
忽略的本地制品目录，不提交凭证、内部环境地址或真实会话内容。
