# 云端个人助理

Studio 的「个人助理」侧栏连接一个专属的 DSH Native 云端部署。模型、云端资源、部署凭证、
运行包与持久卷沿用 Studio / AgentEngine 的现有配置；浏览器只保留所选 Agent、分助理草稿与待确认消息，
不接收云端令牌。

未指定对象存储桶时，部署使用 IAM 核验的主账号和目标区域推导默认桶：
`agentengine-{accountId}-{region}`；预发使用实际存储区域，不把环境别名写进桶名。
高级设置可指定其他桶。运行包保存在独立的 `studio-bundles/v1/` 前缀，上传后校验内容摘要和
匿名访问拒绝；不会覆盖插件制品，也不会自动创建桶或修改桶权限。

第一次打开且尚无助理时，展示「开通个人助理」：沿用默认模型，只有一个记忆库时自动选择，
多个记忆库时只需选择保存位置。确认前明确显示一个 2 核 / 4 GiB 常驻实例、20 GiB 持久盘与
计费提示。点击后显示创建进度，复用现有 Agent、Build 和云端部署服务，不需要依次填写配置页。
开通记录在本机持久保存，重新打开会核对原来的创建结果；重复点击不会另建一个付费实例。
本机创建步骤中断、上传或云端创建结果未知时，显示需要核对的状态，不会一直转圈或自动重复付款。
环境就绪后进入对话，由模型发出欢迎语并保存到 DSH 会话；重开不会重复欢迎。

已有助理时，打开侧栏直接进入对话，输入框固定在底部。只有一个可用助理时自动连接；已有选择时恢复上次的
助理与历史。首次存在多个助理时由用户选择，避免悄悄连接错误的会话。记忆、计划任务与连接选择
放在系统“设置 → 个人助理”中，打开设置不会重置对话或草稿。右上角连接卡片展示实际 Studio Host 设备、系统与在线状态，并可打开原生本机会话。云端个人助理尚未接入本机任务转交，连接卡片不会将 Host 在线解释为云端获得本机执行能力。Enter 发送，Shift + Enter 换行，输入法组词时不发送。

## 生命周期

个人助理是现有 Agent、Build、Deployment 上的产品角色，新建配置带有 `metadata.purpose=personal-assistant`。账号和环境隔离的开通回执记录本地配置、云端 Agent 和部署的对应关系，旧配置通过回执识别，不改写已保存的 Revision。本地配置继续用于编辑和构建；会话选择器只提供云端个人助理。通过本地配置发起的新绑定会在 Host 中解析并核验对应云端实例，不会在云端不可用时回退本地执行。原先已开始的本地会话保留原执行身份，页面提示用云端助理开启新会话。

任务失败状态来自 DSH 的回合结束记录，页面显示失败原因；仅在失败回合有唯一、完整的人工请求归属时提供重试，定时任务或混合输入不会误重跑上一条人工消息。工具调用产生的空消息不显示成回复。重试已失败任务使用新的请求标识；未知提交结果仍沿用原标识核对，避免重复执行。原始模型和工具错误保存在云端日志，公开快照只返回固定提示，避免泄露凭证。

云端镜像启用 `personal-assistant/v1` 能力，并提供 Bearer 认证的
`POST /v1/assistant/{operation}`。Studio 先核对部署回执、运行包身份与实时能力，再转发请求。
旧镜像返回需要更新的提示，不会静默降级为随连接断开而取消的执行。

`submit` 调用 DSH Session Controller 的队列接口，并等待 DSH `sessions.flush` 确认保存后
返回 202。请求标识与内容指纹由 DSH 保存；客户端确认结果未知时保留待发送消息，重试使用原标识。
在快照中看见消息仅证明原生会话已经观察到请求，不等于落盘确认。因此未知 ACK 的原请求标识不会被快照清除；“确认提交”使用同一标识再次经过 DSH 去重与 flush。关闭页面或本地 Host 不会取消云端任务。

停止使用 `cancel-turn` 和 `personal-assistant-cancel-turn/v1` 能力，携带当前回合编号与开始序列。云端在同一个同步步骤中核对官方 `turnBoundary` 状态并请求取消；若后续排队任务已开始，则拒绝旧停止请求，避免停止错误任务。取消 ACK 仅显示正在停止，原生终态确认后才显示停止。旧镜像没有此能力时，界面提示更新，不回退到不限定回合的取消。

重新连接通过 DSH 历史分页恢复内容，不维护第二份会话数据库。公开快照只保留安全的原生会话事件；客户端把它们交给已安装 DSH 的 `ConversationNodeAssembler` 和事件定义，复用原生 Markdown、DisclosureRow、StateDot 与 ImageLightbox 展示文字、工具和嵌套工具结果、图片、产物、任务状态及审批记录。重连和加载更早记录会合并去重，近期页面移动不会丢掉已经看过的历史。

原生输入使用独立的云端 Client graph：公开 `conversation.content` 工厂、真实 `SessionReference`、Connection/Gateway/Remote/Controller 都绑定到当前部署的受限 carrier。即使两台 Host 的 Session ID 相同，也不会进入本地会话。原生 prompt 适配回原有 durable submit + flush；不会改用断开即取消的 `/v1/responses`。输入采用仅上传、内存草稿、仅队列发送的实例配置，本地 DSH 的默认行为不变。原生停止与 steer 不开放，页面仍使用精确回合停止接口。

## 附件、输入与能力边界

`attachment-upload` 通过官方 `fileUploads` 保存字节，返回属于当前云端 Session 的上传回执。图片也先上传，再在 `submit.content` 中引用回执；服务端核对归属和内容后交给原生图片准入，不把图片伪装成文本文件或本机路径。支持只发图片、文件或图文混合。客户端草稿与待确认 journal 只保存回执和必要元数据，不保存 base64；切换助理或离开视图会取消未完成的本地读取/传输，并忽略迟到结果，不取消已经提交的后台任务。

新内容协议的指纹覆盖完整规范化内容及其语义字段，未知 ACK 使用原 requestId 和原内容重放。有效回执走原生提交的去重流程；回执已消费或 Host 重启后，云端通过公开原生历史核对原请求与完整指纹，并再次 flush 后确认。因此重放不会凭空生成新请求，正常新提交也不扫描全部历史。尚未提交的 staged 回执由原生服务持有，Host 重启后可能失效；界面明确要求重新选取，不能自动换 requestId 重发结果未知的任务。

单附件最多 20 MiB、每条最多 8 个附件、总附件字节最多 32 MiB，图片还受原生图片尺寸/模型能力限制。消息文字最多 32000 字。只有上传操作使用专用、有界的大请求入口；通用 Host 控制 RPC 仍限 1 MiB，云端普通提交仍限 256 KiB。专用入口要求精确路径和上传操作白名单，继续由 DSH Connection 验证准入。浏览器到 Host 和 Host 到云端都沿用现有认证通道，令牌不下发浏览器。

| 内容或操作 | 当前行为 | 授权与限制 |
| --- | --- | --- |
| 新图片/文件输入 | 先上传取得云 receipt，再持久提交 | 会话归属、类型、数量、大小与完整性验证；失败/取消可恢复 |
| 原生图片引用 | 云端预览和 lightbox | 仅可见会话内真实引用；raster MIME；对象 URL 随视图释放 |
| 原生 file 附件引用 | 可下载 | 服务器按可见会话重新授权，完整读取并核验 SHA-256；浏览器用惰性 binary blob 下载 |
| path-only `deliverables/presented` | 仅展示生成记录 | 上游没有不可变附件回执或安全快照；不能把路径或额外伪造字段当成下载权限 |
| 实时审批 | 新建 managed 助理可对已支持敏感工具逐次确认 | 需真实在线 carrier、准确操作预览及原生 allowed-once；既有助理不自动升级 |
| 历史审批记录 | 只读 | 从不恢复为可点击批准请求 |
| 云到本机交接 | 已实现绑定/确认/拒绝协议和纯模拟执行器 | 生产不连接本机，能力为不可用；模拟回执明确 `executed:false` |
| 原生跨 Host 输入 | 已接通独立云 graph 和原生输入组件 | 权限、模型切换、命令、steer、本机路径等不在 carrier 白名单内；工具与多模态历史继续走安全原生组装器 |

产物边界及实际符号链接竞态反例见[云端产物下载安全边界](assistant-deliverable-download-safety.md)。`display.files` 只表示原生附件文件下载能力，`display.deliverables` 单独保持 `metadata-only`。云端 Markdown 隔离本机文件打开与图片路径委托，文件下载不会打开本机同名文件。

审批桥的答案绑定 Host、Session、回合开始序列、请求代次和有效期；一次允许/拒绝后不可重放。审批 ACK 只说明答案被接收，不能当作工具执行成功。新建 managed 助理的桥由实际收到 ready 并持续消费事件的原生 carrier 维持在线事实；关闭、释放、流中断或 35 秒在线期限到达会撤销未完成审批，重连不复活旧请求。普通 HTTP 快照、历史事件和浏览器开关不能维持询问权。后台常规任务继续执行，遇到需要确认而无人在线的敏感动作时拒绝该动作，不取消无关队列。

新开通流程要求镜像明确支持 `personal-assistant-workspace-managed/v1`，并在确认前说明能力。新助理采用 `workspace-managed/v1`：专属云工作区内的官方读、写、编辑、glob 和 grep 可自主执行；单个普通文件删除需要展示路径、大小和摘要并逐次批准。任意 Shell、未知 MCP、外部发送、支付、账号/权限变更和越出工作区均未开放，不能因为名称像普通工作就自动执行。外部副作用目前没有可信默认适配器，界面不能承诺点击批准即可使用。固定搜索模板属于有边界执行，不等于任意程序执行。

这是新助理真实、持久的原生 workspace-write/ask 产品配置，不是先改 ask 再恢复的临时授权。既有只读助理、已有 Session 和未知版本不自动迁移；本轮未实现存量助理原地升级按钮，升级需显式新配置/新部署与数据迁移确认。启动时先安装只拒绝的守卫，验证专属目录回执后再接管；缺失配置、验证失败、模型关闭或恢复未完成时不会暴露持久可写会话。最终工具派发还校验经过审批的定义/执行函数未被替换。完整能力与真实文件系统约束见[权限模型](assistant-permission-model.md)。

本机交接不接受来自 JSON 的 `approved:true` 作为授权，确认必须来自可信执行端回调；确认之后重新核对执行器身份、连接代次、具体动作摘要和当前回合。当前仅支持纯模拟的有界相对文件读取意图，没有 shell、写入、网络、凭据或权限操作，也不会实际读取用户文件。

不展示模型内部上下文和推理文本；原始工具参数及失败诊断不进入公开事件。成功结果中常见凭据字段会脱敏。旧镜像保留文字历史，并在使用新附件、审批或停止接口前明确拒绝缺少的能力。

会话按 Agent、冻结 Build 和会话键寻址。关闭与重新打开相同部署可以恢复；更换 Build 会进入
新的版本状态目录，目前不承诺跨版本迁移。云端实例应使用持久卷和单副本常驻部署；本版本不提供
跨副本调度、故障中任务恰好执行一次或全天候 SLA。

## 定时任务

镜像显式安装并启用 `@deepseek-ai/dsh-experimental-schedule-bundle`。助理的计划、时钟、
持久化、会话恢复和投递复用官方 `schedule` 服务，Studio 只提供当前助理的管理入口。
第一版表单提供延迟一次性任务，执行结果回到原会话。列表中的投递状态不等于模型任务执行成功。

插件运行在云端 Host，因此 Studio 可以退出。安装在桌面 Host 的同一个插件只会随本地 Host 运行。
现有运行中心的 AgentEngine 云端自动化仍保留：它的执行记录、外部投递与平台调度语义不同，
不能直接用单 Host 的会话提醒替换。旧本地自动化暂未迁移或删除；后续迁移需逐条映射计划、保留
停用回执，并验证没有双重触发后移除旧调度器。

## 记忆与积累

绑定记忆库后，沿用既有资源适配器与分区规则。用户可以查看、补充、纠正、删除长期记忆；
修改必须收到云端有效回执，提取异步完成时不能把“已接收”显示为“已记住”。
会话的记忆召回与写入策略沿用 Agent 配置。这里的“进化”指积累并修正事实、偏好和经验，
不包含自动改写程序、扩大权限或自行安装插件。

第一版面向一个专属部署服务一个用户，不能把同一部署令牌分发给互不信任的多个用户。
记忆管理当前最多展示前 100 条；删除长期记忆不会删除原始会话记录。

## 关闭并删除

在“设置 → 个人助理 → 连接”中关闭助理，需要确认删除专属云端部署、会话、工作区文件和该助理分区内的记忆。计划任务先停止，共享知识库及记忆库实例保留。重新启用需要新建助理，旧记忆不会恢复。关闭本地应用窗口不会删除云端助理。

删除要求云端镜像声明 `personal-assistant-delete/v1`。Host 只清理由冻结运行包回执证明的独立目录；先停止写入和清理专属数据，再删除受当前账号部署回执约束的云端实例。旧镜像需要更新，不能把断开连接显示为删除成功。数据清理或云端删除结果未知时保留待处理状态和删除记录，供再次核对。

在系统设置的“个人助理 → 连接”中，可保存“助理名字”和“如何称呼你”。名字独立保存在专属部署中，不依赖可选的语义记忆库；会话标题和连接卡片使用同一份配置。DSH 原生系统提示词在每次模型请求时读取该身份，包含重启恢复和定时任务；已有历史不改写。修改需要镜像声明 `personal-assistant-identity/v1`。关闭并删除助理会一并删除身份配置；部署整体替换前应保留其专属数据卷。
