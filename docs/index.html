RUNTIMES

三种运行时，同一个工作台

同一个 Agent 定义，可以跑在三种运行时上：DSH 原生、自研 AgentKit Harness，或 Codex。按任务挑运行时，不必换工具、不必重写编排。

dsh-native

DSH Native Harness

DSH 原生运行时。内置工具、会话与补丁体系完整，适合日常研发、长上下文与需要精细控制的任务。

runtime: "dsh-native" tools: 内置工具集 loop: 可审阅 · 可回放
harness

AgentKit Harness

自研 Harness 运行时。可插拔的 Agent 循环，工具集、上下文策略与运行环境都能按团队口径定制。

runtime: "harness" plugins: 可插拔 deploy: 本地 / 云端一致
codex

Codex Agent

Codex 运行时。面向代码任务，直接接入仓库、测试与工具调用，把改动留在可审阅的轨迹里。

runtime: "codex" scope: 仓库 · 测试 trace: 工具调用可查

WORKFLOW

从一句话，到可交付结果

AgentKit Studio 把对话、工具、文件和后台任务放在同一个循环里，每一步都留痕、可审阅。

01

描述目标

说清楚你想完成什么，引用工作区文件，或让 Agent 先检查现状。

02

让 Agent 执行

它会选择合适的插件和工具，持续反馈进展，并保留可审阅的改动。

03

继续完善

直接在对话中提出下一轮要求，直到结果可以交付、可以复用。

DEVELOPERS

开发者体验

从命令行启动，或基于源码构建。插件、补丁与测试全部在公开仓库里。

命令启动

安装 Node.js 后，通过 npx 启动 Web UI。

terminal
$ npx @kingsoftcloud/agentkit-studio web

源码安装

获取完整项目源码，并按仓库说明完成安装。

terminal
$ git clone https://github.com/kingsoftcloud/agentkit-studio.git
$ cd agentkit-studio
$ npm install && npm test
