从一句话，到可交付结果

AgentKit Studio 把对话、工具、文件和后台任务放在同一个循环里。

1 · 描述目标

说清楚你想完成什么，引用工作区文件，或让 Agent 先检查现状。

2 · 让 Agent 执行

它会选择合适的插件和工具，持续反馈进展，并保留可审阅的改动。

3 · 继续完善

直接在对话中提出下一轮要求，直到结果可以交付。

# 从源码启动
$ npx @kingsoftcloud/agentkit-studio web

# 或安装公开包
$ git clone https://github.com/kingsoftcloud/agentkit-studio.git
$ cd agentkit-studio
$ npm install && npm test
